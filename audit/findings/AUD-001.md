# AUD-001: Accounts CI allows database-dependent tests to skip (no DATABASE_URL)

- Type: Test coverage gap
- State: Fixed 2026-09-20; verified locally; CI run pending push
- Severity / rationale: made green CI say nothing about transactional auth/key storage (superseded in scope by AUD-015)
- Confidence and evidence basis: source-confirmed at baseline and HEAD; fix verified by workflow inspection + local gate
- Owner: remediation wave 0
- Affected repositories, revisions, and local patches: `betterbase-accounts` fix `8f44b39` (base `b7cda8872ee0`) (`.github/workflows/check.yml`)
- Violated invariant / linked decision: plan Stage 4 enforced-gate criterion; companion to AUD-060

## Impact and preconditions

CI ran `cargo test` without a database; storage tests (once they exist) would silently skip.

## Evidence and reproduction

Workflow comment and test step at baseline revision ([baseline evidence](../evidence/2026-09-20-baseline-accounts.md)).

## Remediation

Mirrors the betterbase-sync CI pattern: `postgres:17-alpine` service container, `DATABASE_URL` plus `BB_TEST_REQUIRE_DB=1` env on the test step; stale skip-comment replaced with the enforced-gate description. `SQLX_OFFLINE=true` retained (job-level) so compile-time macros use committed `.sqlx` metadata.

## Verification

Local `just test-db` proves the same env combination runs storage tests and fails on missing DB; the GitHub Actions run itself is pending push. Verifier: remediation agent, 2026-09-20.
