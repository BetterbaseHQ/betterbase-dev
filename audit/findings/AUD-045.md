# AUD-045 — Prior account's records visible to another account / unauthenticated views

**Audit finding (E-01):** all six persistent apps opened fixed database names with no account scoping; app-level queries delivered every record, so account B saw account A's decrypted records (password reveal included) and five apps exposed them pre-auth. Session cleanup clears auth storage, not application records.

**Policy (user-selected):** per-account databases with a retained anonymous namespace. Anonymous/local data is deliberately retained (local-first; never deleted on switch); each signed-in account gets its own database; isolation is structural, not query-filtered (the reviewer explicitly rejected filtering as "not an account filter").

**Fix** (`betterbase-examples` commit `7726b6b`, SDK `f60ad60`):
- Shared helpers: `accountScopeKey` (personal space ID → handle → constant), `accountDbName` (`base_<sha256-prefix>`; name charset is alphanumeric/underscore/hyphen), `useDbScope`, `DbScopeGate`.
- Each app's `db.ts` exports a **live** `db` binding swapped by `openDatabaseForScope` (no-op when the requested scope is already open); the App root gates rendering on readiness and remounts the entire tree (React key) on every scope change, so no component observes a mid-swap database. Capturing the binding is documented as a caveat.
- SDK testing double: `useSyncDb` prefers the mounted stub provider's `adapter` (mirroring the real provider) over the `setSyncDb` snapshot.

**Regressions:** `accountDbName` derivation (distinct/stable per scope, no raw identifier embedded); end-to-end isolation against the real local adapter in `tasks/src/lib/db.test.ts` — records written under A are invisible to B, survive A→B→A untouched, anonymous namespace survives every switch; same-scope reopen is a no-op. Test harness adjustments (scope pre-alignment, `findByRole` after render, widened boot waits) are documented in the commit.

**Verification:** all six apps' `pnpm check` green; shared check green; platform e2e green (photos/tasks/board flows exercise the apps end-to-end). **Status:** Fixed (wave 6).
