# AUD-034: Invitations after rotation label the current key as epoch one

- Type: Defect
- State: Fixed 2026-09-20; verified locally + platform e2e 121/121 ([evidence](../evidence/2026-09-20-remediation-wave2a.md))
- Owner: remediation wave 2a
- Affected repositories: `betterbase-sync` `c32f747`, `betterbase` `1a69f84`
- Violated invariant: INV-03/04/05 as applicable

## Remediation (implemented)

Invitation metadata carries the key's generation; recipient persists it as the space epoch (legacy payloads default to 1); invite/rotate fall back to the persisted record epoch.
