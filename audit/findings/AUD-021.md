# AUD-021 — Structural decoder trusts declared counts beyond available input

- **Register**: B-05, Defect, High
- **Report**: `audit/reviews/02-local-data.md` §B-05 (**reproduced**: 7 input bytes → 100000 decoded slots)
- **Fixed**: 2026-09-21, wave 5

## Root cause (confirmed)

`CrdtReader` returns zero/empty past EOF (`u8`, `buf`, `utf8`), and the structural decoder's count-driven loops materialize elements from those zeros: a declared vector length of 100000 with no payload decoded into 100000 null slots. `decode_vec_logical` additionally indexed `r.data[r.x]` directly — a panic past EOF. Malicious or corrupted imported/decrypted models could force allocations unbounded by input size.

## Fix

`crates/json-joy/src/json_crdt/codec/structural/binary.rs`:

- `require_input(r)` guard at every count-driven element iteration (all twelve loops: server + logical obj/vec/str/bin/arr, including nested arr spans) — a cursor at/past EOF while elements remain is a truncated model → `DecodeError::EndOfInput`. Every element consumes ≥1 byte, so well-formed input is never rejected.
- Binary chunk spans shorter than their declared length (clamped `buf`) are rejected.
- `read_cbor_value`'s off-by-one at-end guard tightened to `>=`.

Divergence from upstream (which materializes zeros) documented in `tests/compat/PARITY_AUDIT.md` per repo rules — the register classifies this as a clear bug, which the repo's AGENTS.md permits fixing with documented divergence.

Commit: json-joy-rs `4cb1ade`.

## Regression tests

- `truncated_vec_count_errors_instead_of_allocating` — the 7-byte/100000-slot reproduction.
- `truncated_logical_vec_does_not_panic` — the former direct-index panic path.
- `truncated_bin_chunk_span_errors` — declared span (50) exceeding payload (3).

All json-joy-rs gates pass (`just fmt/lint/test-gates/test`, 97 suites).

## Notes

- With the guard, decoded size is bounded by input size × constant; the SDK's separate input-size cap now bounds work as well as bytes.
- betterbase's `betterbase-db` consumes json-joy-rs as a path dependency; the full platform e2e ran green against the fixed decoder.
