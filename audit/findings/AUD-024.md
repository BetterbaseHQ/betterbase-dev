# AUD-024: Revoked subscribers retain future ciphertext access and can derive future keys

- Type: Defect
- State: Fixed 2026-09-20; verified locally + platform e2e 121/121 ([evidence](../evidence/2026-09-20-remediation-wave2b.md))
- Owner: remediation wave 2b (decision D-005)
- Affected repositories: `betterbase-sync` `159a0ff`, `betterbase` `52d6f64`

## Remediation (implemented)

Fresh random rotation keys distributed as per-member JWE-wrapped shares (server-stored epoch_keys, distribute-before-rewrap, pull-based adoption); revocation detaches the removed member's subscriptions per space (connection preserved for other spaces; re-subscribe rejected by authorization).
