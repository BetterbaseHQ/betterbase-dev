# AUD-006: Registration can overwrite an existing username's credentials

- Type: Defect
- State: Fixed 2026-09-20; verified locally ([evidence](../evidence/2026-09-20-remediation-wave1.md)); platform e2e verified 121/121 (2026-09-20)
- Severity / rationale: Critical — account takeover by claiming an existing username with a fresh verified email
- Confidence and evidence basis: source-confirmed, cross-verified
- Owner: remediation wave 1
- Affected repositories, revisions, and local patches: `betterbase-accounts` fix `6cd6f62` (handlers/auth.rs, storage accounts.rs, storage lib.rs + cleanup.rs, app lib.rs)
- Violated invariant / linked decision: INV-04/05; D-004

## Impact and preconditions

`password/init` resolved accounts by submitted username with a token bound only to the email; the upsert silently returned the existing row and finalize unconditionally replaced credentials. See review 01 A-04.

## Remediation (implemented)

Layered: handler rejects a username held by a different email or a registered account (409, before JTI consumption so a taken username does not burn the email verification); storage `get_or_create_account` returns `AccountExists` on username-conflict-with-different-email and on email unique violations (concurrency-safe); `finalize_registration_with_root_key` is compare-and-set on `opaque_record IS NULL` (distinguishing replay vs missing account); a weekly `cleanup_unregistered_accounts` task reclaims abandoned reservations so squatted usernames/emails do not persist forever. Recovery flows (`update_registration*`) intentionally remain overwrite-capable. Genuine resume of an unfinished signup (same email+username, unregistered) still works.

## Verification

Route tests: verified-email-claims-victim-username → 409, victim credentials/wrapper untouched, token still usable on retry; unfinished-signup resume passes. Storage tests: username/email conflict mapping, CAS replay rejection, backdated-reservation cleanup with fresh and registered accounts retained. Verifier: remediation agent, 2026-09-20.
