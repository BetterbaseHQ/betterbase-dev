# AUD-031: WebSocket session authorization outlives JWT expiry

- Type: Defect
- State: Fixed 2026-09-20; verified locally + platform e2e 121/121 ([evidence](../evidence/2026-09-20-remediation-wave2b.md))
- Owner: remediation wave 2b (decision D-005)
- Affected repositories: `betterbase-sync` `159a0ff`, `betterbase` `52d6f64`
- Violated invariant: INV-04/05

## Remediation (implemented)

AuthContext carries the token expiry; the connection deadline is capped at exp + 5s grace and closes with the token-expired code. Fail-closed: token refresh opens a new connection rather than extending the deadline.
